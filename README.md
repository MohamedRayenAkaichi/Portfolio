### 🟢 [Web Infrastructure Security – DDoS & Injection Mitigation](./web-infra-security/)

> **Stack:** Nginx · ModSecurity · CrowdSec · iptables · Docker · Metabase · DVWA — 100% open-source

Design and deployment of a **multi-layer Defense-in-Depth architecture** protecting a vulnerable web application (DVWA) without modifying its source code.

**Architecture overview:**

```
Internet
    │
    ▼
┌─────────────────────────────────────────────────┐
│  Layer 4 – SYN Flood Protection                │
│  Linux kernel SYN Cookies (sysctl)             │
│  iptables hashlimit → per-IP rate limiting     │
└────────────────────┬────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────┐
│  Layer 7 – Nginx Reverse Proxy                 │
│  Aggressive timeouts → Slowloris mitigation    │
│  ModSecurity WAF + OWASP CRS v3                │
│  → Blocks SQLi, XSS, XXE                      │
│  → Virtual patching of sensitive endpoints     │
└────────────────────┬────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────┐
│  Active IPS – CrowdSec                         │
│  Leaky Bucket behavioural detection            │
│  → Auto-bans malicious IPs via IPSet           │
└────────────────────┬────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────┐
│  SOC Dashboard – Metabase                      │
│  Real-time threat visualisation                │
│  KPI reporting on attack patterns              │
└─────────────────────────────────────────────────┘
```

**Key outcomes:**
- SYN Flood attacks neutralised at kernel level with zero service degradation
- SQL injection, XSS, and XXE blocked by WAF without application code changes
- Automated IP banning pipeline with sub-second response time
- Real-time SOC dashboard for threat visibility and KPI tracking
